# Simulador do Brasileirão

Simulador do campeonato brasileiro 2026 com 20 equipes,
38 rodadas e geração de resultados das partidas.

## Tecnologias

- Java
- Programação Orientada a Objetos
- Java Swing
- ...

## Funcionalidades

- Geração das partidas
- Simulação dos resultados
- Atualização da classificação
- Exibição da tabela
- ...

## Como funciona

O sistema simula as partidas do campeonato e atualiza
a classificação das equipes de acordo com os resultados, 
havendo empates, vitórias e derrotas, além de times
mais fortes que outros.

## Projeto

Desenvolvido como projeto acadêmico durante a graduação
em Engenharia de Software.
